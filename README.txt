VfB Datenbank v11 — Installation auf GitHub Pages

1. ZUERST in der alten Version unter „Daten sichern“ ein JSON-Backup herunterladen.
2. Auf github.com ein neues Repository anlegen, z. B. vfb-datenbank.
3. Die Dateien index.html, sw.js, manifest.webmanifest und icon.svg aus diesem Ordner direkt in das Repository-Hauptverzeichnis hochladen (nicht die ZIP-Datei).
4. Unter Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
5. Nach Veröffentlichung die HTTPS-Adresse öffnen: https://BENUTZERNAME.github.io/vfb-datenbank/
6. Auf dem iPhone Safari öffnen, dieselbe HTTPS-Adresse aufrufen, Teilen > Zum Home-Bildschirm.
7. Unter Daten sichern das JSON-Backup auf dem iPhone importieren.

WICHTIG: GitHub Pages stellt die App öffentlich bereit. Deine Einträge bleiben nur im lokalen Browser-Speicher des jeweiligen Geräts; es gibt KEINEN Login und KEINE automatische Synchronisierung. Der iPhone-Speicher ist getrennt vom PC-Speicher. Regelmäßig JSON-Backups exportieren.

Karte: Leaflet/OpenStreetMap-Karten benötigen beim ersten Laden Internet. Für bekannte Stadien sind Koordinaten integriert; für andere Orte erfolgt bei Bedarf eine sparsame Abfrage von OpenStreetMap Nominatim. Fehlen Marker, kannst du beim eigenständigen Stadionbesuch Breitengrad/Längengrad hinterlegen.

Spielkatalog: ausgewählte verifizierte VfB-Spiele 2024/25, 2025/26 und 2026/27. NOCH NICHT VOLLSTÄNDIG; weitere Begegnungen können per CSV ergänzt werden.

Datenschutz: GitHub Pages ist keine private Zugangsbeschränkung. Keine geheimen Daten in index.html oder im Repository hinterlegen.
